# Instruções para agentes

- Leia os documentos relevantes em `docs/` antes de implementar qualquer alteração.
- Trabalhe somente na tarefa solicitada e não expanda o escopo sem autorização.
- Preserve o isolamento multiempresa em todas as decisões.
- Nunca confie somente no frontend para autorização; valide no backend o usuário, o vínculo ativo, o papel e o `salonId`.
- Não armazene segredos, tokens ou credenciais no repositório.
- Use TypeScript estrito e crie testes para regras relevantes.
- Não adicione dependências sem necessidade demonstrada.
- Prefira soluções simples antes de abstrações prematuras.
- Mantenha a branch `main` funcional e use commits pequenos.
- Não faça commit sem solicitação explícita.
- Explique as alterações realizadas e os comandos executados.
